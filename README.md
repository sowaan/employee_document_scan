## Employee Document Scan

This app enables scanning and attaching employee identification documents to ERPNext.

It provides:
- A local image watcher to capture scanned ID images
- Automatic creation of **Scanned Documents**
- A **Scan & Attach ID** workflow on the Employee form
- MRZ data parsing and employee field auto-population

The solution is designed for **local workstation scanners** and integrates seamlessly with Frappe / ERPNext.
